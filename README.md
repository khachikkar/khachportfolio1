# Khachik Karapetyan Portfolio

Double-click `index.html` to open the site in a browser. Keep the files and the assets folder together. The site runs offline without installing anything.

- `index.html` contains the page structure, text, and image references.
- `style.css` controls the colors, typography, and responsive layout.
- `script.js` controls the mobile menu and the selected navigation link.
- `assets/` contains the five stock photos from the original portfolio.

The stock portrait, wordmark, project concepts, email, and social labels are starter content. Replace the portrait and project images in the HTML when your final assets are ready. Add your public email and social profile URLs in the contact section.
